# Quranic Chatbot

An Android app built with **Flutter** for reading, listening to, searching and asking questions about the Holy Quran, with a small **FastAPI** backend hosted on **Vercel**.

> **Start here:** read the [Handbook (PDF)](quranic_chatbot_project/Quranic_Chatbot_Handbook.pdf) to set everything up, and the [Simple Code Guide (PDF)](quranic_chatbot_project/Quranic_Chatbot_Code_Guide_Simple.pdf) to understand how the code works.

## Features

| Feature | What it does |
|---|---|
| Quran reader | 114 Surahs and 30 Juz with Arabic text, English and Urdu translation |
| Recitation audio | Tap a verse to hear it (Mishary Alafasy). Played verses are saved and work offline |
| Auto Play | Plays the next verse automatically and highlights its card (off by default) |
| Search | Search verses by keyword |
| AI chat | Ask a question and get a short answer with verse references |
| Voice chat | Speak your question instead of typing it |
| Recite & Recognize | Recite a verse and the app finds it, showing Arabic, English and Urdu |
| Bookmarks and history | Saved on your phone |
| Settings | 12 themes, English / Urdu / Arabic interface, font size, playback speed and more |

## How it works

```
Flutter app (phone)  <--HTTPS-->  FastAPI backend (Vercel)  <-->  Groq, Gemini, alquran.cloud
```

- The app talks only to the backend, so no secret key is ever inside the APK.
- Chat answers come from Groq, with Gemini as a fallback.
- Verse recognition is **not an AI guess**: the recitation is converted to text and compared with the real Quran text.

## Tech stack

| Part | Technology |
|---|---|
| App | Flutter / Dart, Hive (local database), just_audio, record, http |
| Backend | Python, FastAPI, Groq (Llama / Whisper), Google Gemini |
| Hosting | Vercel |
| Data | alquran.cloud (text and translations), everyayah.com (audio) |

## Quick start

**1. Install the tools:** Git, Flutter, Android Studio, VS Code and Python (details in the handbook).

**2. Create free accounts and API keys:** GitHub, Vercel, [Groq](https://console.groq.com) and [Google AI Studio](https://aistudio.google.com).

**3. Deploy the backend** from the `backend/` folder to Vercel and add these two environment variables in the Vercel project settings:

```
GROQ_API_KEY
GEMINI_API_KEY
```

**4. Prepare the app** (run inside `quranic_chatbot_project/flutter_app`):

```
flutter create . --platforms=android --project-name quranic_chatbot
python tools/add_android_permissions.py
```

**5. Set the backend address:** open `lib/services.dart` and put your Vercel URL in `kBackendBaseUrl`.

**6. Run it on a phone:**

```
flutter pub get
flutter run
```

**7. Build an APK to share:**

```
flutter build apk --release
```

The APK is created at `build/app/outputs/flutter-apk/app-release.apk`.

## Backend

The original hosted backend is in its own repository: [sammar-abbas-shah/quran-backend](https://github.com/sammar-abbas-shah/quran-backend). The `backend/` folder here is a copy of the same code, so you can fork either one.

## Important notes

- **Never commit API keys.** Keys belong only in Vercel environment variables.
- **AI answers can be wrong.** Chat answers are generated by language models. Check the verse references, and ask a qualified scholar for religious rulings.
- Quran text, translations and audio come from established public sources, not from AI.
- Text-to-speech for voice replies is simulated, so voice replies appear as text.
